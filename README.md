# 📊 SQL Practice & Portfolio Projects

Welcome to my SQL practice repository! This project contains hands-on SQL scripts designed to solve real-world data analytics and business intelligence problems.

## 📁 Repository Structure

* `01_customer_loyalty_analysis.sql`: E-commerce customer loyalty ranking using `CASE WHEN`, `GROUP BY`, and `DENSE_RANK()`.
* `02_performance_analysis.sql`: Product performance categorization and sales aggregation.
* `03_user_activity_categorization.sql`: User event log analysis using string manipulation (`LOWER`, `TRIM`) and pattern matching (`LIKE`).

## 🛠️ Concepts & Functions Covered

* **Data Cleaning:** `TRIM()`, `UPPER()`, `LOWER()`
* **Conditional Logic:** `CASE WHEN ... THEN ... ELSE ... END`
* **Aggregation:** `COUNT()`, `SUM()`, `MAX()`, `GROUP BY`
* **Window Functions:** `DENSE_RANK() OVER()`
* **Pattern Matching:** `LIKE '%...'`
