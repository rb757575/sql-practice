# 🔍 SQL Subqueries Introduction

## 🎯 Overview
Practicing SQL subqueries to filter data dynamically using nested queries.

## 🛠️ Concepts Covered
* Using `SELECT`, `FROM`, and `WHERE` clauses together.
* Subqueries with aggregate functions like `AVG()`.
* Row-by-row filtering based on calculated threshold values.

* `04_subqueries_intro.sql`: Contains table creation, sample employee data, and subquery exercises.
